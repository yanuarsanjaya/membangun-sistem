# Python Dasar untuk Pemula (Programmer Zaman Now)

> Kursus Python dasar selama 5 jam 11 menit yang membahas sintaks, tipe data, kontrol alur, struktur data, function, error, file I/O, dan tiga aplikasi kecil.

## Key takeaways

- **Python adalah bahasa tingkat tinggi, interpreted, cross-platform, dan open source.** Sintaksnya sederhana; ia langsung dijalankan tanpa kompilasi, tetapi lebih lambat dan lebih boros memori daripada bahasa terkompilasi (4:42–10:35).
- **Empat tipe data dasar:** integer, float, string, dan boolean. Variabel bersifat dinamis; tipenya bisa berubah selama program berjalan (45:33–54:35).
- **Kontrol alur bergantung pada indentasi.** `if`/`elif`/`else` dan `for`/`while` memakai blok yang menjorok; kesalahan spasi mengubah arti program (1:53:11–1:58:00).
- **Struktur data memungkinkan banyak nilai dalam satu variabel.** Materi mencakup list dan struktur lain seperti tuple, set, dan dictionary (2:47:24–3:16:47).
- **Function adalah blok kode yang bisa dipakai ulang.** Dibuat dengan `def`, bisa menerima parameter dan mengembalikan nilai (3:16:48–3:47:19).
- **Error adalah bagian normal dari pengembangan.** Python memberi pesan yang menunjukkan lokasi dan jenis kesalahan; `try`/`except` menangani error saat runtime (3:47:20–4:06:29).
- **File I/O menyimpan data secara permanen.** Mode `r`, `w`, `a`, dan `x` menentukan apakah file dibaca, ditimpa, ditambah, atau dibuat (4:06:31–4:22:35).
- **Tiga aplikasi penutup menggabungkan semua materi:** kalkulator, permainan tebak angka, dan aplikasi ujian sekolah dengan bank soal (4:22:36–5:10:19).

## Open questions

- Kursus ini berhenti di Python dasar; tidak ada materi tentang virtual environment, package manager, testing, atau async.
- Contoh aplikasi berjalan di terminal, bukan web atau notebook. Untuk analisis data dan AI, pembelajar perlu materi tambahan (pandas, NumPy, Jupyter).
- Klaim bahwa Python "tidak ideal untuk mobile" benar secara umum, tetapi tidak membahas opsi seperti Kivy atau BeeWare.
- Berapa lama waktu latihan yang dibutuhkan setelah menonton 5 jam materi agar benar-benar bisa menulis program sendiri?

## Catatan kualitas sumber

Ini adalah kursus terstruktur dari praktisi berpengalaman, bukan tutorial kilat. Kualitasnya tinggi untuk pemula, tetapi tetap satu sumber: contoh, gaya mengajar, dan pilihan tool (PyCharm, VS Code) adalah preferensi instruktur. Halaman ini merangkum kurikulum, bukan menggantikan latihan.
