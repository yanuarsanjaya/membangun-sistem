# Catatan Analisis Statistik Fisioterapi (SPSS)

## Weight Cases pada Data Frekuensi
- **Konteks**: Saat menganalisis data frekuensi di SPSS (seperti tabel distribusi frekuensi), pastikan menggunakan prosedur **Weight Cases**.
- **Langkah**:  ->  -> *Weight cases by* -> pilih kolom frekuensi.
- **Tujuan**: Agar SPSS menghitung total keseluruhan subjek (misal: 37 subjek) bukan hanya menghitung jumlah baris data frekuensinya (misal: 5 baris).
