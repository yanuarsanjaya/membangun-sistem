# Projects Workspace

Folder kerja hidup untuk proyek aktif dan catatan operasional yang dibagikan secara baca-tulis (`:rw`) ke sandbox Hermes Agent, terpisah dari lapisan sumber baku (`raw/`) dan wiki terkompilasi (`wiki/`).

- `fisioterapi/` — materi pembelajaran dan referensi klinis fisioterapi.
- `penelitian-s2-fisioterapi/` — proposal, tinjauan instrumen, dan catatan tesis S2.
- `trading-dan-analisis-keuangan/` — strategi trading, backtest, dan laporan analisis harian.
