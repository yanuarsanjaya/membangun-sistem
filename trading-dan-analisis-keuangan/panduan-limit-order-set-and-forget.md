# Panduan Eksekusi Limit Order (Set and Forget)

Strategi ini dirancang untuk trader yang ingin memasang *limit order* di area *Support* utama dengan manajemen risiko otomatis (Stop Loss & Take Profit terpasang sekaligus / OCO order) dan ditinggal tanpa harus memantau chart setiap hari.

## Aturan Eksekusi
1. **Modal Total**: Rp 10.000.000
2. **Risiko per Trade**: 1% dari modal = Rp 100.000 (diatur via jarak SL).
3. **Reward**: TP ditetapkan 2x lipat dari jarak SL (Rasio TP:SL = 2:1).
